# Code Rain

Code Rain brings Matrix-style digital rain to the BUSY Bar’s 72×16 front display. Fourteen streams of mirrored katakana fall at staggered speeds, with bright green heads and fading trails.

## How to use

Open **Code Rain** from the Apps menu to start at 1× speed. Code Rain runs offline.

- **Turn the wheel** clockwise to speed up or counterclockwise to slow down. The speed ranges from 0.5× to 2× in 0.25× steps.
- **Press the wheel** briefly to advance one step. At 2×, the next press returns to 0.5×.
- **Press Back** to exit.
